# How Many Tabs Do You Have Open?

Entry for the make.fun bounty `u-danu-how-many-tabs-do-you-have-open-d86e783d`.

The entry is a single number, digits only: **63** — the honest count of open
browser tabs.

Why 63: it is an odd, non-round number that reads as a count someone actually
looked at and counted, not a number picked to shock. It is high enough to
surprise against the usual 10-30 tab field, yet entirely believable for a
heavy tab hoarder — several windows, research rabbit holes, articles saved
"to read later" that never get closed. It hints at a life of never closing
anything, without a word of explanation.

`main.py` writes the number to `/output/entry.txt`. Nothing else is needed.
